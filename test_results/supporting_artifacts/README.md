# Supporting test artifacts

This folder contains the detailed evidence behind the three top-level reports
in `test_results`:

- `raw/` contains command records, test logs, JUnit/Jest/Playwright machine
  results, screenshots and browser HTML output.
- `coverage/` contains generated backend and frontend coverage data and HTML
  views.
- Root JSON/XML files preserve coverage totals, priority-case data and the
  recorded validation manifest.
- `checklist_completion_report.md` maps the project evaluation checklist to
  the repository evidence and states the remaining GitHub-side/manual review
  items.

These files are retained for traceability. Start with the three top-level
Markdown reports for a concise review.
